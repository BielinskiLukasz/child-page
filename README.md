# Spokojny Świat Artura

A calm, silent Polish-language web app for three-year-old Artur. A main menu with large picture tiles opens gentle, touch-driven activities, each with a Back button. **Intended for supervised use by a young child.**

**Try it live: [Spokojny Świat Artura](https://bielinskilukasz.github.io/child-page/)**

All activities are silent and calm, with no scores or failure, and work with touch, mouse or stylus. The Back button in the top-left corner returns to the menu. Parents can hide or reorder activities in Settings; see [Menu activities](#menu-activities).

## Run locally
Plain HTML/CSS/JS, no build step:

```
python3 -m http.server 8000
```
then open http://localhost:8000/. Navigation uses URL hashes and relative paths, so it works from any subpath.

## Install and offline use
The app is an installable PWA (manifest, icons, service worker); it needs HTTPS (GitHub Pages) or localhost.
- **Android Chrome:** open the site, menu ⋮ → **Zainstaluj aplikację** / *Install app*. It opens full-screen from the home-screen icon.
- **iPhone/iPad Safari:** Share → **Do ekranu początkowego** / *Add to Home Screen*.
- **Offline:** after one online load, the menu and all activities work in airplane mode. The service worker (`sw.js`) is network-first, so a new deployment is picked up on the next launch with network; no version bump is needed.
- **Old shortcut:** if a "shortcut" saved before this change misbehaves, remove it once (long-press the icon → remove/uninstall) and install again.
- Icons are generated by `python3 tools/make-icons.py`.

## Deployment
Pushing to `main` runs `.github/workflows/pages.yml`, which publishes to GitHub Pages. In the repo settings set Pages → Source to **GitHub Actions** once.

## Browser support
Mandatory manual tests: Chrome desktop, Chrome Android, Safari iPhone/iPad. Edge and Firefox should work. Zoom is intentionally disabled to avoid accidental pinch-zoom.

## Privacy
No backend, cookies, ads, third-party requests or tracking; no network request is made for analytics. The only things stored, locally on the device (localStorage), are the parent-configured daily playtime limit, the playtime used today (with its date), which activities are shown in the menu, in what order and which are favourites, and the anonymous usage statistics described below; none of it leaves the device. No audio.

## Usage statistics
`js/analytics.js` (`window.Analytics`) is the single module through which every activity reports usage; nothing is shown to the child. It keeps only **daily aggregates** for the last 90 days plus running all-time totals (localStorage key `swa.stats`), never per-event history, names, age, location, text or any device fingerprint. The per-session id is random and kept in memory only.

Measured: sessions (a session ends when the app is closed or after 30 minutes hidden), active vs. inactive time (active = page visible and a touch/key/pointer less than 60 s ago), activity starts, active time, completions, replays (re-opening in the same session), exits before completion, quick exits (within 10 s), touches, the highest level reached in the levelled activities, and **interaction variants** reported as aggregate counts only (for example the dog breed, the rocket part, the letter, the scoop or tip, the machine or the product). Nothing per-event, personal or networked is stored. See [docs/activities/README.md](docs/activities/README.md) for the per-activity status.

## Playtime limit
A gear icon on the main menu opens a parent gate (a simple sum) and then Settings: daily limit in minutes (default 20, or no limit) and a timer reset. The timer counts only visible activity time and resets each new day. An hourglass (no numbers) shows time left, content dims gently over the last 20%, and when time is up a sleeping-moon screen is shown.

## Menu activities
In Settings (behind the same gate) a parent can enable or disable each activity and reorder them with up/down buttons; "Przywróć domyślne" restores all of them in the original order. At least one activity always stays enabled, and disabled activities cannot be opened by any route (a stored or typed `#hash` shows the menu).

**Favourites.** Each Settings row also has a star toggle (filled ★ = favourite, outlined ☆ = not). Enabled favourites appear in an "Ulubione" section above the other tiles, in their saved list order, and are not repeated below; with no enabled favourites no heading is shown. A disabled activity is hidden even if starred and returns to the section when re-enabled. Only a parent can change favourites (the child has no control); they are stored locally with the menu configuration and "Przywróć domyślne" clears them. Starring is not reported to usage statistics.

## Randomisation helper
`js/animals.js` (loaded after `random.js`) exposes `window.Animals`, the shared animal family drawn in one round-head style (13 animals: Miś, Króliczek, Kotek, Piesek, Myszka, Świnka, Lisek, Lew, Słoń, Panda, Żabka, Sowa, Koala): `Animals.head(id, opts)` returns the SVG markup, `Animals.pick(n, {distinct})` returns `n` random unique animals (`distinct` avoids alike silhouettes). Pociąg, Dobranoc, Farma, Chowany, Cienie, Autobusik and Buźki pick their animals from it on every launch, in memory only.

`js/random.js` (loaded before the activities) exposes `window.Rand` for activity variety, kept in memory only (nothing stored, nothing scored): `Rand.shuffle(list)` returns a new shuffled copy; `Rand.pick(list, n)` returns `n` unique items (the whole pool shuffled if `n` exceeds it); `Rand.pickOne(list, key)` returns one item that differs from the previous result for the same `key` in this page session when the pool has 2+ entries. An empty pool gives `[]` / `undefined`.
